# Red Dead Redemption 2 — Mission Index

**Game:** Red Dead Redemption 2
**Category:** Story missions
**Tier:** 1
**Source reference:** Red Dead Redemption 2 mission lists; see project research notes.

Red Dead Redemption 2 has a large story campaign divided into Chapters 1–6 and two epilogue parts. The source used for this index lists 108 story-mission entries; other completion guides count optional/variant objectives differently, so counts can vary by definition.
