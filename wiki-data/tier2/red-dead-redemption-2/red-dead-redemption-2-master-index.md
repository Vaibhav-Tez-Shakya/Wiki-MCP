# Red Dead Redemption 2 — Master Index

**Game:** Red Dead Redemption 2  
**Tier:** 1  
**Category:** Story-Based Game / Complete Game Reference

## Overview

Red Dead Redemption 2 is an open-world action-adventure game developed by Rockstar Games.

The main narrative is divided into six chapters followed by two epilogue parts. This Tier 1 dataset contains the game's main story structure, chapter missions, epilogue missions, stranger/side missions, companion item requests, and game-level commercial information.

## Commercial / Sales Data

- **Total copies sold:** More than **65 million copies**.
- **Franchise context:** Red Dead Redemption 2 is one of the best-selling video games of all time.
- **Game:** Red Dead Redemption 2
- **Release:** 2018
- **Developer:** Rockstar Games
- **Publisher:** Rockstar Games

> Sales figures should be treated as time-dependent metadata and updated when a newer officially reported figure becomes available.

### Tier 1

RDR2 is maintained in Tier 1 as a complete game-level reference dataset.

Tier 1 contains:

- Game overview
- Commercial / sales information
- Main story structure
- Chapter mission data
- Epilogue mission data

## Maintenance Rules

1. Keep all RDR2 Tier 1 data inside the RDR2 Tier 1 directory.
2. Do not delete existing chapter, epilogue, side-mission, or companion data when updating the dataset.
3. Preserve internal relative links between RDR2 files.
4. Keep game-level metadata separate from individual mission details.
5. Do not treat compressed `OR` / branch entries as a literal mission count.
6. When adding mission data, preserve the chapter and progression structure.
7. Update sales information when a newer reliable figure becomes available.
8. Tier 2 and Tier 3 must not replace or remove the complete Tier 1 game reference.
9. Any Tier 2/Tier 3 classification must follow the project's sales-based access policy.
10. Validate links and file structure after major data changes.
